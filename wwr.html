🏞️ White Water Rafting Project

This project showcases my work on a multi-page rafting website built with HTML and CSS. The goal was to design an engaging layout that highlights adventure, teamwork, and outdoor fun while maintaining clean code and responsive design.

Project Overview

I created a rafting website that includes a home page, contact page, and trips page. I used Flexbox and Grid to align content, styled the navigation bar with hover effects, and built image galleries to showcase rafting adventures.

  • 💧 Focused on consistent color schemes and readable fonts
  • 🌄 Practiced layout alignment using CSS Grid and Flexbox
  • 🚣 Learned how to optimize hero images for faster loading
  • 📱 Built responsive layouts that look great on mobile and desktop
